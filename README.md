# Reading Africa

A curated digital resource for understanding Africa — across countries, contexts, histories, and futures. Built with **React**, **TypeScript**, and **Vite**.

**Live demo:** https://tomiabe.github.io/reading-africa/

---

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
3. Build for production:
   `npm run build`
4. Deploy to GitHub Pages:
   `npm run deploy`
